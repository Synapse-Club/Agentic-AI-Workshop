# 🤖 Synapse Agentic AI Workshop

### Build Your First AI Agent

📅 **Date:** 19 September 2026  
🏫 **Organized by:** Synapse Club  
💻 **Mode:** Hands-on Workshop

Welcome to the official repository for the Synapse Agentic AI Workshop.

In this workshop, you will learn how to build AI-powered applications and
agents using modern GenAI frameworks and tools.

---

## 🚀 What You Will Learn

- Understanding LLMs and Generative AI
- Working with LLM APIs
- LangChain
- Retrieval-Augmented Generation (RAG)
- Vector databases with ChromaDB
- LangGraph
- Building AI Agents
- Model Context Protocol (MCP)
- Connecting AI agents with external tools
- Building a practical Agentic AI application

---

## 🛠️ Prerequisites

### Software

- Python 3.10+
- VS Code / Jupyter Notebook
- Git
- GitHub account

### Python Libraries

- LangChain
- LangGraph
- ChromaDB
- MCP
- Other libraries provided during the workshop

### Accounts

- GitHub account
- LLM API account/API key
  - Azure OpenAI or Groq
- Claude account for MCP session

### Hardware

- Individual laptop preferred
- Minimum 8 GB RAM
- 16 GB RAM recommended
- No dedicated GPU required

### Knowledge Required

You should have basic knowledge of:

- Python programming
- Functions
- Classes
- APIs

You do NOT need prior knowledge of:

- RAG
- AI Agents
- LangChain
- LangGraph
- MCP
